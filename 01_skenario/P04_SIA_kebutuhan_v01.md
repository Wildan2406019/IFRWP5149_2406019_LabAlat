# Pertemuan 4 — Sistem Informasi Akademik, Layanan Hasil Studi

## 1. Kebutuhan Tugas

| ID      | Kebutuhan tugas                                                                                     |
| ------- | --------------------------------------------------------------------------------------------------- |
| SIA-R07 | Mahasiswa dan Dosen, sebagai Civitas Akademika, dapat melihat kalender akademik.                    |
| SIA-R08 | Dosen dapat menginput nilai mata kuliah yang diampunya.                                             |
| SIA-R09 | Mahasiswa dapat melihat KHS untuk semester yang nilainya sudah dipublikasikan.                      |
| SIA-R10 | Admin Akademik dapat mengelola data mahasiswa.                                                      |
| SIA-R11 | Pengelolaan data mahasiswa terdiri dari tiga fungsi khusus: tambah, ubah, dan hapus data mahasiswa. |
| SIA-R12 | Model menunjukkan collaboration yang merealisasikan Input Nilai Mata Kuliah dan Lihat KHS.          |

## 2. Batas Sistem

- Sistem yang dianalisis adalah Sistem Informasi Akademik (SIA).
- Kalender akademik yang digunakan merupakan agenda resmi institusi.
- Penginputan nilai dilakukan oleh dosen yang mengampu mata kuliah terkait.
- Mahasiswa hanya dapat melihat KHS yang nilainya sudah dipublikasikan.
- Penghapusan data mahasiswa hanya dilakukan terhadap mahasiswa yang tidak memiliki data akademik aktif.
- Pengajuan KRS tetap digambarkan sebagai bagian dari diagram kumulatif Pertemuan 3.
- Pembayaran dan perancangan basis data berada di luar lingkup tugas ini.

## 3. Asumsi

- Pengguna sudah masuk ke sistem dan memiliki hak akses sesuai perannya.
- Data kalender akademik tersedia di dalam sistem.
- Data mata kuliah dan dosen pengampu tersedia sebelum penginputan nilai dilakukan.
- Nilai yang diinput dosen belum dianggap resmi sebelum dipublikasikan sesuai ketentuan institusi.
- KHS hanya menampilkan nilai untuk semester yang sudah dipublikasikan.
- Admin Akademik memiliki kewenangan untuk menambah, mengubah, dan menghapus data mahasiswa sesuai batas yang ditentukan.
